# Global_seismic_trends
Global Seismic Trends: Data-Driven Earthquake InsightsLeveraged SQL and Python to analyze global seismological data, uncovering critical patterns in earthquake frequency, magnitude, and geographical distribution. Built an interactive Streamlit dashboard using Regular Expressions (Regex) for advanced data cleaning and text parsing of geological reports. This project bridges data analytics and geoscience, translating complex seismic data into actionable insights for disaster management and risk mitigation.
